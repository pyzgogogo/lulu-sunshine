# 噜噜 · 阳光里，仍有你

一张珍藏噜噜日常的陪伴纪念闪卡。

[打开闪卡](https://pyzgogogo.github.io/lulu-sunshine/)

新版入口：[直接打开](https://pyzgogogo.github.io/lulu-sunshine/?v=2)。

可拖动转动、翻卡读信、摸摸噜噜、拖动羽毛玩具、留下暖阳，并保存正反面图片。卡背有三段可切换的小回忆，也能写一句想念。留言只保存在当前设备的浏览器里，分享链接不会携带留言；保存卡背图片可以把它一起留住。

手机首屏先显示约 256 KB 的完整 JPEG 卡面，再渐进加载分层视差。互动使用 HTML/CSS 3D，不依赖 WebGL、Three.js、GLB 或远程配置加载；图片层失败时仍保留完整卡面和翻卡功能。系统减少动态效果的设置会关闭动画。界面已移除四个参数滑杆。

基于 [Holo Card Studio](https://github.com/EverettFish/holo-card-studio) 和 Three.js 制作，软件许可已附带。卡面图像参考用户提供的照片生成，不包含原始照片。图像与软件许可分别适用。
